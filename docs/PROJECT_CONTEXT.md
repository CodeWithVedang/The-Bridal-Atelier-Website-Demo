## 4. Hard constraints (from the brief)

- No fake or real-looking contact data. Phone, WhatsApp, email, address are **configuration placeholders**.
- No fabricated proof: no invented awards, statistics, certifications, review counts, or press.
- No `Lorem ipsum`. No AI-boilerplate voice.
- No external API is wired up (Instagram feed is local sample data).
- Pricing must read as investment, never as discount.
- Do not simply scale desktop down; design mobile as its own layout.
- Fix defects rather than reporting them.

Next.js 16 behaviours that changed the implementation plan:

- `params` / `searchParams` / `cookies()` / `headers()` are **async** — always awaited.
- `middleware.ts` is renamed `proxy.ts` (Node runtime only) — we ship none.
- `error.tsx` receives **`retry`**, not `reset`.
- `next/image` defaults changed: `qualities: [75]`, `minimumCacheTTL: 14400`, `remotePatterns` only.
- Global type helpers `PageProps<'/route'>`, `LayoutProps<'/route'>`, `RouteContext<'/route'>` are generated by `next typegen` / `next dev` / `next build`.
